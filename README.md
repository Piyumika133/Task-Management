
Task Management System

A web-based Task Management System developed using PHP, HTML, and a database, providing user authentication and task management functionality through a simple and structured interface.

Key Features & Project Structure

User Authentication: Supports user registration, login, logout, session management, and authorization.
Task Management:Allows authenticated users to create and retrieve tasks from the database.
Database Integration: Centralized database configuration and connection through `db.php`.
Backend API Scripts: PHP scripts handle authentication, user management, task creation, and task retrieval.
Frontend Interface: `task-manager.html` provides the main user interface for interacting with the application.
Testing: Includes `test.php` for basic PHP environment and functionality testing.
Documentation: `README.md` provides project setup and usage information.

Main Components

`add_task.php` • `auth.php` • `db.php` • `get_task.php` • `login.php` • `logout.php` • `register.php` • `task-manager.html` • `test.php`

 Technologies
